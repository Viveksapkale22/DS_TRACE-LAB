CP_FUNDAMENTALS

Fundamentals of C programming, module by module. Every module has basic concepts and step-by-step tracing programs you can run, step through and re-run with your own inputs.

How to use: click a module box, pick a program number, read the basic concept, then press Next to watch each line run. Change the inputs and trace again. Yellow text in the console is what the user types.

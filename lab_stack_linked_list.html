Basic concept

A stack is LIFO: Last In, First Out. In a linked list stack, every element is a node created with malloc that holds data and a next pointer. The pointer top always points to the newest node.

push adds a node at the top (O(1)). pop removes the top node and frees its memory (O(1)). Unlike an array stack there is no fixed size, so overflow only happens if malloc fails.

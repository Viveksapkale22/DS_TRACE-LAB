Postfix Expression Evaluation using Stack

Postfix Expression :
Use single digits 0-9 and + - * / (spaces are ignored). Try 123*+ or 5+ to see an underflow.
Rule: read left to right. A digit is pushed. An operator pops two values (the first pop is val2, the second is val1), computes val1 operator val2, and pushes the result back. The last value left is the answer.

Queue using a Linked List

1. Stack (Linked List)2. Queue (Linked List)3. Reverse Linked List

Basic concept

A queue is FIFO: First In, First Out. A linked list queue keeps two pointers: front (where we remove) and rear (where we add). Both operations are O(1) because we never walk the list.

enqueue links a new node after rear. dequeue removes the node at front. When the last node leaves, rear must also be set to NULL, otherwise it would point to freed memory.

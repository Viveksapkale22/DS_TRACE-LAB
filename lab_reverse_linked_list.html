Reversing a Singly Linked List

1. Stack (Linked List)2. Queue (Linked List)3. Reverse Linked List

Basic concept

A singly linked list node only knows the node after it. To reverse the list we do not move any data. We only flip every next pointer to point backwards, using three helper pointers: prev (node behind), curr (node being fixed) and next (saved so we do not lose the rest of the list).

Each loop does 4 things: save next, flip the link, move prev forward, move curr forward. At the end prev is the old last node, so it becomes the new head. Time O(n), extra space O(1).
